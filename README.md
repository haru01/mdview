# mdview

ターミナル上で Markdown を読みやすく表示する TUI ビューア。SVG・画像・Mermaid 図をインラインでレンダリングします。

## 特徴

- **読みやすい表示** — [Textual](https://textual.textualize.io/) ベースの TUI。見出しやテーブルに階層を付けたスタイリング。
- **画像のインライン表示** — PNG / JPG / GIF / WebP / BMP を端末内に描画。
- **SVG レンダリング** — `cairosvg` でラスタライズして表示。
- **Mermaid 図** — `mermaid` コードフェンスを図として描画（別途 `mmdc` が必要、後述）。
- **diff の見やすい表示** — `gh pr diff` などの unified diff をパイプすると、ファイル・`@@` ハンクを見出し化し、追加行を緑・削除行を赤に色分けして表示（後述）。
- **目次（TOC）** — トグルで表示し、ツリーをキーボードで辿れる。
- **リンク追跡** — 別の `.md` ファイルへのリンクを開き、`b` で戻れる。アンカー（`#section`）にも対応。
- **段階的な選択** — 同じ場所を繰り返しクリックするか `v` キーを押すたびに、選択範囲が Markdown の構造（ブロック → リスト項目 → リスト/引用 → セクション → 全体）に沿って段階的に広がる。`V` で 1 段ずつ縮小。Ask AI と組み合わせて段落やセクションを手早く選べる。
- **AI に質問（Ask AI）** — 本文を選択して `h` を押すと、選択範囲について `claude` に質問できる（別途 `claude` CLI が必要、後述）。
- **stdin 入力** — `mdview -` でパイプから読み込み。
- **非 TTY フォールバック** — パイプや CI など端末でない出力先には整形済みテキストを出力。

## インストール

[uv](https://docs.astral.sh/uv/) を使う場合（推奨）。リポジトリのルートで:

```sh
# どこからでも mdview コマンドを使えるようにする
uv tool install .

# 開発しながら使う場合は editable で
uv tool install --editable .
```

既にインストール済みで入れ直したいときは `--force` で上書きします。コード変更を確実に反映するには `--reinstall`（キャッシュを使わず再ビルド）も併用します:

```sh
uv tool install --force .              # 上書き再インストール
uv tool install --force --reinstall .  # 再ビルドして反映
```

インストールせず都度実行する場合（プロジェクトディレクトリ内）:

```sh
uv run mdview README.md
```

## 使い方

```sh
mdview path/to/file.md      # ファイルを開く
cat notes.md | mdview -     # stdin から読み込む
gh pr view 123 | mdview -   # 他コマンドの出力をそのまま表示
gh pr diff 123 | mdview -   # diff を色分け・見出し付きで表示（後述）
mdview file.md | less       # 非 TTY 出力時は整形テキストを出力
```

stdin 入力時、相対パスの画像・リンクはカレントディレクトリ（CWD）を基準に解決します。

### キーバインド

| キー | 動作 |
| --- | --- |
| `j` / `↓` | 1 行下へスクロール |
| `k` / `↑` | 1 行上へスクロール |
| `Ctrl+d` / `Ctrl+u` | 半ページ下 / 上 |
| `g` / `G` | 先頭 / 末尾へ |
| `n` / `p` | 次 / 前の見出しへジャンプ（diff 表示ではファイル・`@@` ハンク単位） |
| `t` | 目次（TOC）の表示切り替え |
| `b` / `←` | 直前のファイルへ戻る |
| `v` / `V` | 選択範囲を Markdown 構造に沿って拡大 / 縮小（同じ場所のクリック連打でも拡大） |
| `h` | 選択中のテキストについて AI に質問（Ask AI） |
| `?` | ヘルプパネルの表示切り替え |
| `q` / `Esc` | 終了 |

### 段階的な選択（`v` / `V`）

選択範囲を Markdown の構造に沿って 1 段ずつ広げ／狭めできます。長い段落やセクションを正確に選ぶのに便利で、そのまま Ask AI（`h`）へ渡せます。

- **`v`（拡大）** — 押すたびに 1 段階広がります。最初はビューポート先頭のブロックを選択し、以降は次の構造単位へ。
- **`V`（縮小、Shift+v）** — 1 段階狭めます。最小単位でもう一度押すと選択を解除します。
- **マウス** — ブロックを 1 回クリックすると選択、同じ場所をもう一度クリックするたびに 1 段階広がります。別のブロックをクリックすると、その位置から選び直します。

広がる順序（ラダー）:

```
ブロック（段落・見出し・コードブロック・リスト項目・表）
  → リスト項目 → リスト／引用
  → セクション（見出し区切り。下位の見出しを含む）
  → 親セクション → … → ドキュメント全体
```

たとえば見出し `### H3` をクリック／`v` すると、`H3` 見出し → `H3` のセクション → それを含む `## H2` セクション → ドキュメント全体、と段階的に広がります。

### Ask AI

本文を選択してから `h` を押すとポップアップが開きます。選択はマウスのドラッグのほか、段落・セクションを繰り返しクリック（または `v` キー）して段階的に広げる方法も使えます。質問を入力して `Enter` を押すと、開いているドキュメントの全文と選択した抜粋・質問が `claude -p` に渡され、回答が表示されます（`Esc` で閉じる）。

回答は開いているファイルの内容を文脈として生成されます（リポジトリ全体ではなく、そのドキュメントが対象）。

### diff の表示

`gh pr diff` や `git diff` の出力をパイプすると、生の unified diff を自動検出し、機械的に構造化 Markdown へ変換して表示します。各ファイルは見出し、各 `@@` ハンクも見出しになり、追加行は緑・削除行は赤に色分けされます。

```sh
gh pr diff 123 | mdview -
```

`n` / `p` でファイル・`@@` ハンク単位に素早く移動でき、`t`（目次）は diff のアウトラインになります。`.diff` / `.patch` ファイルを直接開いた場合も同様に表示されます。

## 必要なもの

- Python 3.11 以上
- Mermaid 図を表示する場合は [`@mermaid-js/mermaid-cli`](https://github.com/mermaid-js/mermaid-cli) の `mmdc` が PATH 上に必要:

  ```sh
  npm install -g @mermaid-js/mermaid-cli
  ```

  `mmdc` が見つからない場合、Mermaid フェンスはコードブロックのまま表示されます。

- Ask AI（`h`）を使う場合は [`claude`（Claude Code）](https://claude.com/claude-code) CLI が PATH 上に必要。見つからない場合は `h` を押すとその旨を通知します。

uv sync          # 依存関係をインストール
